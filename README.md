# TechNomads Web

Public website, account portal, store, and authenticated integration API for the TechNomads Minecraft community.

## Status

Bootstrap repository. The implementation will be recreated deliberately and added through reviewed pull requests.

## Repository scope

Included: Next.js application, Firebase configuration, Stripe integration, public assets, and web-focused tests.

Not included: Minecraft runtime files, bot processes, deployment credentials, generated modpack archives, and production data.

## Contributing

Open an issue before substantial work. Submit changes through a focused pull request and document the verification performed.
