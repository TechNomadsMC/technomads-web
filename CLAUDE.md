# CLAUDE.md

## Repository purpose

Public website, account portal, store, and authenticated integration API for the TechNomads Minecraft community.

## Working rules

- Read README.md and relevant documentation before changing files.
- Work on a feature branch and deliver changes through a pull request.
- Keep each change focused; do not refactor unrelated code.
- Never commit secrets, credentials, production data, logs, backups, or generated artifacts.
- Add complete implementations without placeholders.
- Add or update automated verification with every functional change.
- Run the repository's documented checks before requesting review.
- Update architecture and setup documentation when behavior or boundaries change.
- Deploy only through the repository's approved GitHub workflow.

## Boundary

Included: Next.js application, Firebase configuration, Stripe integration, public assets, and web-focused tests.

Excluded: Minecraft runtime files, bot processes, deployment credentials, generated modpack archives, and production data.
